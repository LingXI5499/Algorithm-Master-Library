# 02 - 树状数组 (Fenwick Tree / BIT)

## 1. 概念解释

### 什么是树状数组？

树状数组（Binary Indexed Tree，BIT）利用二进制低位（`lowbit`）将数组分层，实现 **O(log n)** 的单点更新和前缀和查询。

**核心公式**：`lowbit(x) = x & (-x)`（取 x 二进制的最低位 1）

```
树状数组内部结构示意（n=8）：
tree[1] = a[1]
tree[2] = a[1] + a[2]
tree[3] = a[3]
tree[4] = a[1] + a[2] + a[3] + a[4]
tree[5] = a[5]
tree[6] = a[5] + a[6]
tree[7] = a[7]
tree[8] = a[1]+...+a[8]
```

每个 `tree[i]` 负责 `[i - lowbit(i) + 1, i]` 范围的和。

## 2. 基本操作

### 单点更新 + 前缀和查询

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e5 + 5;
int tree[MAXN], n;

// x 位置加 val（下标从 1 开始）
void update(int x, int val) {
    for (; x <= n; x += x & (-x))
        tree[x] += val;
}

// 查询 [1, x] 的前缀和
int query(int x) {
    int sum = 0;
    for (; x > 0; x -= x & (-x))
        sum += tree[x];
    return sum;
}

// 查询区间 [l, r] 的和
int queryRange(int l, int r) {
    return query(r) - query(l - 1);
}

// 将 x 位置的值设为 val（先查原值，再差值更新）
void set(int x, int val, int* a) {
    update(x, val - a[x]);
    a[x] = val;
}
```

### 建树：O(n) 建树

```cpp
// 方法1：逐个 update，O(n log n)
void build(vector<int>& a) {
    for (int i = 1; i <= n; i++) update(i, a[i-1]);
}

// 方法2：O(n) 建树
void buildFast(vector<int>& a) {
    for (int i = 1; i <= n; i++) {
        tree[i] += a[i-1];
        int j = i + (i & (-i));
        if (j <= n) tree[j] += tree[i];
    }
}
```

## 3. 区间修改 + 单点查询

利用差分数组思想：对差分数组建树状数组。

```cpp
// 区间 [l, r] 加 val
void rangeUpdate(int l, int r, int val) {
    update(l, val);
    update(r + 1, -val);
}

// 单点查询（对差分数组求前缀和）
int pointQuery(int x) {
    return query(x);
}
```

## 4. 区间修改 + 区间查询

需要维护两个树状数组：

```
若 diff[i] 是差分数组，则
sum(1..x) = Σ_{i=1}^{x} a[i] = Σ_{i=1}^{x} Σ_{j=1}^{i} diff[j]
          = Σ_{j=1}^{x} diff[j] * (x - j + 1)
          = (x+1) * Σ diff[j]  -  Σ (j * diff[j])
```

```cpp
long long bit1[MAXN], bit2[MAXN];  // bit1 存 diff[i], bit2 存 i*diff[i]

void add(int x, long long v) {
    for (int i = x; i <= n; i += i & (-i)) {
        bit1[i] += v;
        bit2[i] += v * x;
    }
}

// 区间 [l, r] 加 v
void rangeAdd(int l, int r, long long v) {
    add(l, v); add(r+1, -v);
}

long long prefixSum(int x) {
    long long s = 0;
    for (int i = x; i > 0; i -= i & (-i))
        s += (x+1) * bit1[i] - bit2[i];
    return s;
}

// 区间 [l, r] 的和
long long rangeSum(int l, int r) {
    return prefixSum(r) - prefixSum(l-1);
}
```

## 5. 逆序对统计

逆序对：`i < j` 且 `a[i] > a[j]`。  
思路：从左到右处理每个元素，加入树状数组后查询有多少已加入元素比当前元素大。

```cpp
int countInversions(vector<int>& a) {
    // 坐标压缩
    vector<int> sorted = a;
    sort(sorted.begin(), sorted.end());
    sorted.erase(unique(sorted.begin(), sorted.end()), sorted.end());
    auto compress = [&](int x) {
        return lower_bound(sorted.begin(), sorted.end(), x) - sorted.begin() + 1;
    };

    n = sorted.size();
    fill(tree, tree + n + 2, 0);

    long long inv = 0;
    for (int x : a) {
        int cx = compress(x);
        inv += queryRange(cx + 1, n);  // 比 x 大的已出现元素数
        update(cx, 1);
    }
    return inv;
}
```

## 6. 例题：数组中的第 k 大元素（离线）

```cpp
// 利用树状数组的二分（查找第 k 小）
int kthSmallest(int k) {
    int lo = 1, hi = n;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (query(mid) >= k) hi = mid;
        else lo = mid + 1;
    }
    return lo;  // 压缩后的值，需还原
}
```

## 7. 总结

| 功能 | 所需结构 | 查询/更新复杂度 |
|------|----------|----------------|
| 单点修改 + 前缀查询 | 1 个 BIT | O(log n) |
| 区间修改 + 单点查询 | 差分 + 1 个 BIT | O(log n) |
| 区间修改 + 区间查询 | 2 个 BIT | O(log n) |
| 逆序对统计 | 1 个 BIT + 离散化 | O(n log n) |

> **树状数组 vs 线段树**：树状数组常数更小、代码更短，但功能受限；线段树更通用但实现复杂。
