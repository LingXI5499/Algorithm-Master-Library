# 01 - 网络流

## 1. 概念解释

### 流网络

**流网络**是一个有向图 G = (V, E)，每条边 (u, v) 有一个**容量** `c(u, v) ≥ 0`。  
指定一个**源点** s 和**汇点** t，在满足以下条件下寻找从 s 到 t 的最大流：

1. **容量限制**：每条边上的流量 `f(u,v) ≤ c(u,v)`
2. **流量守恒**：除 s、t 外，每个节点流入量 = 流出量

**最大流最小割定理**：最大流 = 最小割（将图分为两部分的边容量之和的最小值）

## 2. Dinic 算法（推荐）

Dinic 算法结合**BFS 分层**和**DFS 多路增广**，时间复杂度：O(V² × E)，对单位容量图为 O(E√V)。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Dinic {
    struct Edge { int to, rev; long long cap; };
    vector<vector<Edge>> graph;
    vector<int> level, iter;
    int n;

    Dinic(int n) : n(n), graph(n), level(n), iter(n) {}

    void addEdge(int from, int to, long long cap) {
        graph[from].push_back({to, (int)graph[to].size(), cap});
        graph[to].push_back({from, (int)graph[from].size()-1, 0});  // 反向边容量为0
    }

    bool bfs(int s, int t) {
        fill(level.begin(), level.end(), -1);
        queue<int> q;
        level[s] = 0; q.push(s);
        while (!q.empty()) {
            int v = q.front(); q.pop();
            for (auto& e : graph[v])
                if (e.cap > 0 && level[e.to] < 0) {
                    level[e.to] = level[v] + 1; q.push(e.to);
                }
        }
        return level[t] >= 0;
    }

    long long dfs(int v, int t, long long f) {
        if (v == t) return f;
        for (int& i = iter[v]; i < (int)graph[v].size(); i++) {
            Edge& e = graph[v][i];
            if (e.cap > 0 && level[v] < level[e.to]) {
                long long d = dfs(e.to, t, min(f, e.cap));
                if (d > 0) {
                    e.cap -= d;
                    graph[e.to][e.rev].cap += d;
                    return d;
                }
            }
        }
        return 0;
    }

    long long maxflow(int s, int t) {
        long long flow = 0;
        while (bfs(s, t)) {
            fill(iter.begin(), iter.end(), 0);
            long long f;
            while ((f = dfs(s, t, LLONG_MAX)) > 0) flow += f;
        }
        return flow;
    }
};
```

### 使用示例

```cpp
int main() {
    int n = 6, m = 9;  // 节点数、边数
    Dinic dinic(n);
    // addEdge(from, to, capacity)
    dinic.addEdge(0, 1, 11);
    dinic.addEdge(0, 2, 12);
    dinic.addEdge(1, 2, 10);
    dinic.addEdge(1, 3, 12);
    dinic.addEdge(2, 4, 11);
    dinic.addEdge(3, 4, 3);
    dinic.addEdge(3, 5, 7);
    dinic.addEdge(4, 5, 15);
    // 源点0，汇点5
    cout << dinic.maxflow(0, 5) << "\n";  // 23
    return 0;
}
```

## 3. 最小费用最大流（MCMF）

在保证最大流的前提下，最小化流的总费用。每条边除容量外还有**费用**。

```cpp
struct MCMF {
    struct Edge { int to, rev, cap, cost; };
    vector<vector<Edge>> graph;
    int n;

    MCMF(int n) : n(n), graph(n) {}

    void addEdge(int from, int to, int cap, int cost) {
        graph[from].push_back({to, (int)graph[to].size(), cap, cost});
        graph[to].push_back({from, (int)graph[from].size()-1, 0, -cost});
    }

    pair<int,int> minCostFlow(int s, int t, int maxf) {
        int flow = 0, cost = 0;
        while (flow < maxf) {
            // SPFA 找最短费用增广路
            vector<int> dist(n, INT_MAX);
            vector<bool> inQ(n, false);
            vector<int> prevv(n), preve(n);
            dist[s] = 0;
            queue<int> q; q.push(s); inQ[s] = true;
            while (!q.empty()) {
                int v = q.front(); q.pop(); inQ[v] = false;
                for (int i = 0; i < (int)graph[v].size(); i++) {
                    auto& e = graph[v][i];
                    if (e.cap > 0 && dist[v] + e.cost < dist[e.to]) {
                        dist[e.to] = dist[v] + e.cost;
                        prevv[e.to] = v; preve[e.to] = i;
                        if (!inQ[e.to]) { q.push(e.to); inQ[e.to] = true; }
                    }
                }
            }
            if (dist[t] == INT_MAX) break;
            // 沿增广路推送流量
            int d = maxf - flow;
            for (int v = t; v != s; v = prevv[v])
                d = min(d, graph[prevv[v]][preve[v]].cap);
            for (int v = t; v != s; v = prevv[v]) {
                graph[prevv[v]][preve[v]].cap -= d;
                graph[v][graph[prevv[v]][preve[v]].rev].cap += d;
            }
            flow += d; cost += d * dist[t];
        }
        return {flow, cost};
    }
};
```

## 4. 网络流的应用

### 二分图最大匹配

将二分图转为流网络：源点连左侧所有节点（容量1），右侧所有节点连汇点（容量1），左右之间原有的边（容量1）。

```cpp
int bipartiteMatch(int left, int right, vector<pair<int,int>>& edges) {
    // 节点编号：0=源, 1..left=左侧, left+1..left+right=右侧, left+right+1=汇
    int s = 0, t = left + right + 1;
    Dinic dinic(t + 1);
    for (int i = 1; i <= left; i++) dinic.addEdge(s, i, 1);
    for (int i = 1; i <= right; i++) dinic.addEdge(left + i, t, 1);
    for (auto [u, v] : edges) dinic.addEdge(u, left + v, 1);
    return dinic.maxflow(s, t);
}
```

## 5. 最大流算法对比

| 算法 | 时间复杂度 | 适用场景 |
|------|-----------|---------|
| Ford-Fulkerson（BFS增广）| O(VE²) | 一般情况 |
| Dinic | O(V²E) | 通用，实际很快 |
| ISAP | O(V²E) | 实践中常比 Dinic 快 |

> 竞赛中推荐使用 **Dinic 算法**，代码量适中，效率高。

## 6. 总结

| 问题 | 建模方式 |
|------|----------|
| 最大流 | 直接建图跑 Dinic |
| 最小割 | 最大流 = 最小割 |
| 二分图最大匹配 | 建流网络跑最大流 |
| 最小费用最大流 | MCMF 算法 |
| 上下界网络流 | 转化为普通最大流 |
