# 03 - 二分查找

## 1. 概念解释

二分查找在**有序**数组（或满足单调性的答案空间）中，每次将搜索范围缩小一半，时间复杂度 **O(log n)**。

**核心思想**：每次取中点 mid，根据 `check(mid)` 决定下一次搜索左半段还是右半段。

---

## 2. 基本框架

### 查找精确值

```cpp
// 在有序数组 a[lo..hi] 中查找 target，返回下标，不存在返回 -1
int binarySearch(vector<int>& a, int target) {
    int lo = 0, hi = (int)a.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;  // 防溢出写法
        if (a[mid] == target) return mid;
        else if (a[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}
```

### 查找左边界（第一个 ≥ target 的位置）

```cpp
// 等价于 lower_bound
int lowerBound(vector<int>& a, int target) {
    int lo = 0, hi = a.size();  // [lo, hi) 左闭右开
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < target) lo = mid + 1;
        else hi = mid;
    }
    return lo;  // 若 lo == a.size()，则 target 比所有元素大
}
```

### 查找右边界（最后一个 ≤ target 的位置 + 1）

```cpp
// 等价于 upper_bound
int upperBound(vector<int>& a, int target) {
    int lo = 0, hi = a.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] <= target) lo = mid + 1;
        else hi = mid;
    }
    return lo;  // 所有 ≤ target 的元素下标 < lo
}
```

### C++ STL 二分

```cpp
#include <algorithm>
vector<int> a = {1, 2, 2, 3, 4, 5};
// lower_bound：第一个 >= val 的迭代器
auto it1 = lower_bound(a.begin(), a.end(), 2);  // 指向 a[1]
// upper_bound：第一个 > val 的迭代器
auto it2 = upper_bound(a.begin(), a.end(), 2);  // 指向 a[3]
// 元素 2 出现的次数
int cnt = it2 - it1;  // 2
```

## 3. 二分答案

当答案具有**单调性**（满足某条件的最小/最大答案）时，可以二分答案，将优化问题转化为判定问题。

**模板**：

```cpp
// 找满足 check(x) 为 true 的最小 x（check 在某个点后从 false 变 true）
int lo = 最小可能答案, hi = 最大可能答案;
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (check(mid)) hi = mid;   // mid 可行，缩小右端
    else lo = mid + 1;           // mid 不可行，缩小左端
}
// lo 即为答案
```

### 例题：木材切割（最大化最小值）

> 有 n 根木材，每根长度为 `a[i]`，用一把高度为 H 的锯横切，能得到每根高于 H 的部分。求至少得到 m 段长度 ≥ L 的木材时，L 的最大值。

```cpp
bool check(vector<int>& a, long long L, long long m) {
    long long cnt = 0;
    for (int x : a) cnt += x / L;
    return cnt >= m;
}

int maxLength(vector<int>& a, int m) {
    long long lo = 1, hi = *max_element(a.begin(), a.end());
    while (lo < hi) {
        long long mid = lo + (hi - lo + 1) / 2;  // 求最大，mid 向上取整
        if (check(a, mid, m)) lo = mid;
        else hi = mid - 1;
    }
    return lo;
}
```

### 例题：在旋转有序数组中查找（LeetCode 33）

```cpp
int search(vector<int>& nums, int target) {
    int lo = 0, hi = nums.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] == target) return mid;
        if (nums[lo] <= nums[mid]) {  // 左半段有序
            if (nums[lo] <= target && target < nums[mid]) hi = mid - 1;
            else lo = mid + 1;
        } else {  // 右半段有序
            if (nums[mid] < target && target <= nums[hi]) lo = mid + 1;
            else hi = mid - 1;
        }
    }
    return -1;
}
```

## 4. 实数二分

当答案为实数时，迭代固定次数（100 次精度已远超 double）：

```cpp
double lo = 0, hi = 1e9;
for (int i = 0; i < 100; i++) {
    double mid = (lo + hi) / 2;
    if (check(mid)) hi = mid;
    else lo = mid;
}
// lo 即为近似答案
```

## 5. 例题汇总

### 搜索插入位置（LeetCode 35）

```cpp
int searchInsert(vector<int>& a, int target) {
    return lower_bound(a.begin(), a.end(), target) - a.begin();
}
```

### 寻找峰值（LeetCode 162）

```cpp
int findPeakElement(vector<int>& nums) {
    int lo = 0, hi = nums.size() - 1;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] < nums[mid + 1]) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}
```

### 第 K 小数（LeetCode 378，有序矩阵）

```cpp
int kthSmallest(vector<vector<int>>& matrix, int k) {
    int n = matrix.size();
    int lo = matrix[0][0], hi = matrix[n-1][n-1];
    auto countLE = [&](int mid) {
        int cnt = 0, j = n - 1;
        for (int i = 0; i < n; i++) {
            while (j >= 0 && matrix[i][j] > mid) j--;
            cnt += j + 1;
        }
        return cnt;
    };
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (countLE(mid) >= k) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
```

## 6. 易错点总结

| 问题 | 处理方式 |
|------|----------|
| 死循环 | 当 `lo + 1 == hi` 时，`mid = lo`，若每次只更新一边需保证收敛 |
| 溢出 | 用 `lo + (hi - lo) / 2` 而非 `(lo + hi) / 2` |
| 边界 | 区分 `[lo, hi]` 闭区间 vs `[lo, hi)` 左闭右开 |
| 求最大 | 满足条件时 `lo = mid`（mid 向上取整：`lo + (hi-lo+1)/2`）|
| 求最小 | 满足条件时 `hi = mid`（mid 正常取中）|
