# 04 - 双指针与滑动窗口

## 1. 双指针

### 概念

双指针技术用**两个指针**协同扫描数组或链表，通常比嵌套循环将 O(n²) 降为 **O(n)**。

**三种模式**：
1. **对撞指针**：左右两端相向移动（有序数组、回文）
2. **快慢指针**：速度不同（链表中点、环检测）
3. **同向双指针**：两指针同向移动（滑动窗口）

## 2. 对撞指针

### 两数之和（有序数组，LeetCode 167）

```cpp
vector<int> twoSum(vector<int>& nums, int target) {
    int lo = 0, hi = nums.size() - 1;
    while (lo < hi) {
        int s = nums[lo] + nums[hi];
        if (s == target) return {lo + 1, hi + 1};
        else if (s < target) lo++;
        else hi--;
    }
    return {};
}
```

### 三数之和（LeetCode 15）

```cpp
vector<vector<int>> threeSum(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    int n = nums.size();
    vector<vector<int>> res;
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i-1]) continue;  // 去重
        int lo = i + 1, hi = n - 1;
        while (lo < hi) {
            int s = nums[i] + nums[lo] + nums[hi];
            if (s == 0) {
                res.push_back({nums[i], nums[lo], nums[hi]});
                while (lo < hi && nums[lo] == nums[lo+1]) lo++;
                while (lo < hi && nums[hi] == nums[hi-1]) hi--;
                lo++; hi--;
            } else if (s < 0) lo++;
            else hi--;
        }
    }
    return res;
}
```

### 盛最多水的容器（LeetCode 11）

```cpp
int maxArea(vector<int>& height) {
    int lo = 0, hi = height.size() - 1, ans = 0;
    while (lo < hi) {
        ans = max(ans, (hi - lo) * min(height[lo], height[hi]));
        if (height[lo] < height[hi]) lo++;
        else hi--;
    }
    return ans;
}
```

## 4. 滑动窗口

### 概念

滑动窗口维护一段连续区间 `[left, right]`，通过移动右端扩大窗口，移动左端缩小窗口，保持窗口满足某个条件。

**通用模板**：

```cpp
int left = 0;
// 窗口状态（如字符频率、当前和等）
for (int right = 0; right < n; right++) {
    // 1. 将 nums[right] 加入窗口
    // ...

    // 2. 当窗口不满足条件时，收缩左端
    while (/* 不满足条件 */) {
        // 移除 nums[left] 的贡献
        left++;
    }

    // 3. 此时窗口满足条件，更新答案
    ans = max(ans, right - left + 1);
}
```

### 固定大小窗口

**示例：大小为 k 的子数组的最大和**

```cpp
int maxSumSubarray(vector<int>& nums, int k) {
    int n = nums.size(), windowSum = 0, ans = INT_MIN;
    for (int i = 0; i < n; i++) {
        windowSum += nums[i];
        if (i >= k) windowSum -= nums[i - k];
        if (i >= k - 1) ans = max(ans, windowSum);
    }
    return ans;
}
```

### 可变大小窗口

**无重复字符的最长子串（LeetCode 3）**

```cpp
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> cnt;
    int left = 0, ans = 0;
    for (int right = 0; right < (int)s.size(); right++) {
        cnt[s[right]]++;
        while (cnt[s[right]] > 1) {
            cnt[s[left]]--;
            left++;
        }
        ans = max(ans, right - left + 1);
    }
    return ans;
}
```

**最小覆盖子串（LeetCode 76）**

```cpp
string minWindow(string s, string t) {
    unordered_map<char, int> need, window;
    for (char c : t) need[c]++;
    int left = 0, valid = 0;
    int start = 0, minLen = INT_MAX;

    for (int right = 0; right < (int)s.size(); right++) {
        char c = s[right];
        window[c]++;
        if (need.count(c) && window[c] == need[c]) valid++;

        while (valid == (int)need.size()) {
            if (right - left + 1 < minLen) {
                minLen = right - left + 1;
                start = left;
            }
            char d = s[left++];
            if (need.count(d) && window[d] == need[d]) valid--;
            window[d]--;
        }
    }
    return minLen == INT_MAX ? "" : s.substr(start, minLen);
}
```

**找所有字母异位词（LeetCode 438）**

```cpp
vector<int> findAnagrams(string s, string p) {
    if (s.size() < p.size()) return {};
    vector<int> cnt(26, 0);
    for (char c : p) cnt[c - 'a']++;

    vector<int> window(26, 0), res;
    int k = p.size();
    for (int i = 0; i < (int)s.size(); i++) {
        window[s[i] - 'a']++;
        if (i >= k) window[s[i - k] - 'a']--;
        if (window == cnt) res.push_back(i - k + 1);
    }
    return res;
}
```

**长度最小的子数组（LeetCode 209，和 ≥ target）**

```cpp
int minSubArrayLen(int target, vector<int>& nums) {
    int left = 0, sum = 0, ans = INT_MAX;
    for (int right = 0; right < (int)nums.size(); right++) {
        sum += nums[right];
        while (sum >= target) {
            ans = min(ans, right - left + 1);
            sum -= nums[left++];
        }
    }
    return ans == INT_MAX ? 0 : ans;
}
```

## 5. 总结

| 技术 | 适用场景 | 复杂度 |
|------|----------|--------|
| 对撞指针 | 有序数组两数/三数之和、回文 | O(n) |
| 快慢指针 | 链表中点、环检测 | O(n) |
| 固定窗口 | 大小固定的子数组统计 | O(n) |
| 可变窗口 | 最短/最长满足条件的子串 | O(n) |

> **滑动窗口的关键**：明确什么时候扩大窗口（右移 right），什么时候缩小窗口（右移 left），以及如何高效更新窗口内状态。
