# 07 - 动态规划基础

## 1. 概念解释

### 什么是动态规划？

动态规划（DP）将问题拆解为**重叠子问题**，通过记录子问题的解避免重复计算，自底向上（或记忆化自顶向下）求解。

**DP 的四个要素**：
1. **状态定义**：`dp[i]` 或 `dp[i][j]` 表示什么？
2. **状态转移方程**：如何从已知状态推出新状态？
3. **初始值**：边界条件是什么？
4. **答案**：最终从哪里读取？

## 2. 线性 DP

### 爬楼梯（LeetCode 70）

每次可以爬 1 或 2 步，n 阶楼梯有多少种爬法？

```
dp[i] = dp[i-1] + dp[i-2]
```

```cpp
int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int c = a + b; a = b; b = c;
    }
    return b;
}
```

### 最大子数组和（Kadane 算法，LeetCode 53）

```
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

```cpp
int maxSubArray(vector<int>& nums) {
    int dp = nums[0], ans = nums[0];
    for (int i = 1; i < (int)nums.size(); i++) {
        dp = max(nums[i], dp + nums[i]);
        ans = max(ans, dp);
    }
    return ans;
}
```

### 打家劫舍（LeetCode 198）

不能抢相邻房屋，最大金额？

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

```cpp
int rob(vector<int>& nums) {
    int n = nums.size();
    if (n == 1) return nums[0];
    int prev2 = nums[0], prev1 = max(nums[0], nums[1]);
    for (int i = 2; i < n; i++) {
        int cur = max(prev1, prev2 + nums[i]);
        prev2 = prev1; prev1 = cur;
    }
    return prev1;
}
```

## 3. 最长递增子序列（LIS）

### O(n²) DP

```
dp[i] = 以 nums[i] 结尾的最长严格递增子序列长度
dp[i] = max(dp[j] + 1)  ∀ j < i && nums[j] < nums[i]
```

```cpp
int lengthOfLIS_n2(vector<int>& nums) {
    int n = nums.size(), ans = 1;
    vector<int> dp(n, 1);
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++)
            if (nums[j] < nums[i]) dp[i] = max(dp[i], dp[j] + 1);
        ans = max(ans, dp[i]);
    }
    return ans;
}
```

### O(n log n) 贪心 + 二分

```cpp
int lengthOfLIS(vector<int>& nums) {
    vector<int> tails;  // tails[i]：长度为 i+1 的最长 IS 的最小末尾
    for (int x : nums) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return tails.size();
}
```

## 4. 最长公共子序列（LCS，LeetCode 1143）

```
dp[i][j]：s1[0..i-1] 与 s2[0..j-1] 的 LCS 长度

若 s1[i-1] == s2[j-1]：dp[i][j] = dp[i-1][j-1] + 1
否则：             dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

```cpp
int longestCommonSubsequence(string s1, string s2) {
    int m = s1.size(), n = s2.size();
    vector<vector<int>> dp(m+1, vector<int>(n+1, 0));
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = (s1[i-1] == s2[j-1])
                     ? dp[i-1][j-1] + 1
                     : max(dp[i-1][j], dp[i][j-1]);
    return dp[m][n];
}
```

## 5. 股票买卖（状态机 DP）

**买卖股票的最佳时机（LeetCode 121）**：最多一次交易。

```cpp
int maxProfit(vector<int>& prices) {
    int minPrice = INT_MAX, ans = 0;
    for (int p : prices) {
        ans = max(ans, p - minPrice);
        minPrice = min(minPrice, p);
    }
    return ans;
}
```

**买卖股票含冷冻期（LeetCode 309）**：

```cpp
int maxProfit(vector<int>& prices) {
    int n = prices.size();
    // hold：持有股票; sold：刚卖出（冷冻中）; rest：不持有且不冷冻
    int hold = INT_MIN, sold = 0, rest = 0;
    for (int p : prices) {
        int prevHold = hold, prevSold = sold, prevRest = rest;
        hold = max(prevHold, prevRest - p);   // 继续持有 or 今天买入
        sold = prevHold + p;                  // 今天卖出
        rest = max(prevRest, prevSold);       // 今天休息
    }
    return max(sold, rest);
}
```

## 6. 区间 DP

### 戳气球（LeetCode 312）

```
dp[i][j]：戳破 (i,j) 之间（不含 i 和 j）的所有气球能得到的最大金币
枚举最后一个戳破的气球 k（[i+1, j-1] 中），它贡献 nums[i]*nums[k]*nums[j]
dp[i][j] = max(dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])
```

```cpp
int maxCoins(vector<int>& nums) {
    nums.insert(nums.begin(), 1);
    nums.push_back(1);
    int n = nums.size();
    vector<vector<int>> dp(n, vector<int>(n, 0));
    for (int len = 2; len < n; len++) {
        for (int i = 0; i + len < n; i++) {
            int j = i + len;
            for (int k = i+1; k < j; k++)
                dp[i][j] = max(dp[i][j], dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j]);
        }
    }
    return dp[0][n-1];
}
```

### 矩阵链乘法

```cpp
// p[i] 是第 i 个矩阵的行数，p[i+1] 是列数
// dp[i][j]：从第 i 到第 j 个矩阵连乘的最小乘法次数
int matrixChain(vector<int>& p) {
    int n = p.size() - 1;
    vector<vector<int>> dp(n, vector<int>(n, 0));
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            dp[i][j] = INT_MAX;
            for (int k = i; k < j; k++)
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + p[i]*p[k+1]*p[j+1]);
        }
    }
    return dp[0][n-1];
}
```

## 7. 记忆化搜索（自顶向下 DP）

有时递归写法更直观，加记忆化避免重复计算：

```cpp
// 不同路径（LeetCode 62）
unordered_map<int, int> memo;

int uniquePaths(int m, int n) {
    if (m == 1 || n == 1) return 1;
    int key = m * 200 + n;
    if (memo.count(key)) return memo[key];
    return memo[key] = uniquePaths(m-1, n) + uniquePaths(m, n-1);
}
```

## 8. 总结

| DP 类型 | 特征 | 代表题 |
|---------|------|--------|
| 线性 DP | 状态按位置递推 | 爬楼梯、打家劫舍 |
| 最长子序列 | LIS、LCS | LeetCode 300、1143 |
| 状态机 DP | 多状态切换 | 股票系列 |
| 区间 DP | 枚举区间分割点 | 戳气球、石子合并 |
| 记忆化搜索 | 递归 + memo | 不同路径 |

> **DP 解题步骤**：定义状态 → 写转移方程 → 确定初始值 → 确定计算顺序 → 优化空间
