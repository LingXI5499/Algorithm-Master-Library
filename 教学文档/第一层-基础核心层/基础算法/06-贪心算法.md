# 06 - 贪心算法

## 1. 概念解释

### 什么是贪心？

贪心算法在每一步**局部最优**的选择，期望得到全局最优解。

**贪心算法成立的条件**：
1. **贪心选择性质**：局部最优选择不影响后续子问题的最优性
2. **最优子结构**：问题的最优解包含子问题的最优解

> 贪心算法不需要回溯，但**需要严格证明**其正确性（通常用反证法或交换论证）。

## 2. 经典贪心问题

### 区间调度（活动选择）

**问题**：给定 n 个区间，选出最多的**互不重叠**的区间数。

**贪心策略**：按**右端点升序**排序，每次选右端点最小且不与已选区间重叠的区间。

```cpp
int maxNonOverlap(vector<pair<int,int>>& intervals) {
    // 按右端点排序
    sort(intervals.begin(), intervals.end(),
         [](auto& a, auto& b){ return a.second < b.second; });
    int ans = 0, end = INT_MIN;
    for (auto& [l, r] : intervals) {
        if (l >= end) { ans++; end = r; }
    }
    return ans;
}
```

### 无重叠区间（LeetCode 435）

**问题**：最少删除多少区间，使剩余区间互不重叠。

```cpp
int eraseOverlapIntervals(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end(),
         [](auto& a, auto& b){ return a[1] < b[1]; });
    int keep = 0, end = INT_MIN;
    for (auto& iv : intervals) {
        if (iv[0] >= end) { keep++; end = iv[1]; }
    }
    return intervals.size() - keep;
}
```

### 用最少数量的箭戳破气球（LeetCode 452）

```cpp
int findMinArrowShots(vector<vector<int>>& points) {
    sort(points.begin(), points.end(),
         [](auto& a, auto& b){ return a[1] < b[1]; });
    int arrows = 0, end = INT_MIN;
    for (auto& p : points) {
        if (p[0] > end) { arrows++; end = p[1]; }
    }
    return arrows;
}
```

## 3. 跳跃游戏

**跳跃游戏 I（LeetCode 55）**：能否到达最后一个位置。

```cpp
bool canJump(vector<int>& nums) {
    int maxReach = 0;
    for (int i = 0; i < (int)nums.size(); i++) {
        if (i > maxReach) return false;          // i 不可达
        maxReach = max(maxReach, i + nums[i]);   // 更新最远可达
    }
    return true;
}
```

**跳跃游戏 II（LeetCode 45）**：最少跳跃次数。

```cpp
int jump(vector<int>& nums) {
    int n = nums.size(), jumps = 0, curEnd = 0, farthest = 0;
    for (int i = 0; i < n - 1; i++) {
        farthest = max(farthest, i + nums[i]);
        if (i == curEnd) { jumps++; curEnd = farthest; }
    }
    return jumps;
}
```

## 4. 分糖果 / 分配问题

**分发糖果（LeetCode 135）**：相邻孩子评分高的至少多一颗糖果。

```cpp
int candy(vector<int>& ratings) {
    int n = ratings.size();
    vector<int> candy(n, 1);
    // 从左到右：右比左高则多一颗
    for (int i = 1; i < n; i++)
        if (ratings[i] > ratings[i-1]) candy[i] = candy[i-1] + 1;
    // 从右到左：左比右高则取最大
    for (int i = n - 2; i >= 0; i--)
        if (ratings[i] > ratings[i+1]) candy[i] = max(candy[i], candy[i+1] + 1);
    return accumulate(candy.begin(), candy.end(), 0);
}
```

## 5. 哈夫曼编码（Huffman Coding）

**思想**：频率高的字符使用更短的编码，用最小堆每次合并两个最小权值节点。

```cpp
int huffmanCost(vector<int>& weights) {
    priority_queue<int, vector<int>, greater<int>> pq(weights.begin(), weights.end());
    int total = 0;
    while (pq.size() > 1) {
        int a = pq.top(); pq.pop();
        int b = pq.top(); pq.pop();
        total += a + b;
        pq.push(a + b);
    }
    return total;
}
```

## 6. 股票买卖

**买卖股票的最佳时机 II（LeetCode 122）**：可多次交易，求最大利润。

```cpp
int maxProfit(vector<int>& prices) {
    int profit = 0;
    for (int i = 1; i < (int)prices.size(); i++)
        profit += max(0, prices[i] - prices[i-1]);
    return profit;
}
```

## 7. 会议室 / 区间合并

**合并区间（LeetCode 56）**：

```cpp
vector<vector<int>> merge(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end());
    vector<vector<int>> res;
    for (auto& iv : intervals) {
        if (res.empty() || res.back()[1] < iv[0])
            res.push_back(iv);
        else
            res.back()[1] = max(res.back()[1], iv[1]);
    }
    return res;
}
```

## 8. 总结

| 类型 | 贪心策略 | 排序依据 |
|------|----------|----------|
| 区间调度 | 选右端点最小 | 按右端点升序 |
| 最少箭射气球 | 同上 | 按右端点升序 |
| 跳跃游戏 | 每步维护最远可达 | 无需排序 |
| 哈夫曼编码 | 合并最小两个 | 最小堆 |
| 股票交易 | 累加所有正增量 | 无需排序 |

> **贪心 vs DP**：能用贪心就用贪心（更简洁），但贪心需要严格证明；DP 更通用但开销更大。
