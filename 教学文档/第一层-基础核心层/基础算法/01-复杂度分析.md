# 01 - 复杂度分析

## 1. 时间复杂度

### 大 O 记号

大 O 表示算法执行时间随输入规模 n 增长的**上界**。只保留增长最快的项，忽略系数和低次项。

| 复杂度 | 名称 | n=10³ 时大约操作数 |
|--------|------|-------------------|
| O(1) | 常数 | 1 |
| O(log n) | 对数 | 10 |
| O(n) | 线性 | 10³ |
| O(n log n) | 线性对数 | 10⁴ |
| O(n²) | 平方 | 10⁶ |
| O(n³) | 立方 | 10⁹ |
| O(2ⁿ) | 指数 | 天文数字 |

### 竞赛中的经验估算

> 一般认为 10⁸ 次基本操作约需 1 秒。

| 时间限制 1s，n 的范围 | 适合的算法复杂度 |
|----------------------|-----------------|
| n ≤ 12 | O(2ⁿ) |
| n ≤ 25 | O(2^(n/2))（折半枚举）|
| n ≤ 100 | O(n³) |
| n ≤ 1000 | O(n²) |
| n ≤ 10⁵ | O(n log n) |
| n ≤ 10⁶ | O(n) 或 O(n log n) |
| n ≤ 10⁹ | O(log n) 或 O(√n) |

## 2. 常见代码的复杂度分析

### 单循环 → O(n)

```cpp
for (int i = 0; i < n; i++)
    // 常数操作
```

### 嵌套循环 → O(n²)

```cpp
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        // 常数操作
```

### 二分 → O(log n)

```cpp
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (check(mid)) lo = mid + 1;
    else hi = mid;
}
```

### 递归复杂度（主定理）

递归式：`T(n) = a·T(n/b) + f(n)`

- 若 `f(n) = O(n^(log_b a - ε))`：`T(n) = Θ(n^(log_b a))`
- 若 `f(n) = Θ(n^(log_b a))`：`T(n) = Θ(n^(log_b a) · log n)`
- 若 `f(n) = Ω(n^(log_b a + ε))`：`T(n) = Θ(f(n))`

**举例**：
- 归并排序：`T(n) = 2T(n/2) + O(n)` → `T(n) = O(n log n)`
- 二叉搜索：`T(n) = T(n/2) + O(1)` → `T(n) = O(log n)`

## 3. 空间复杂度

空间复杂度衡量算法使用的**额外**内存空间（不含输入本身）。

| 算法 | 空间复杂度 |
|------|-----------|
| 冒泡排序 | O(1) |
| 归并排序 | O(n) |
| 递归深度为 d | O(d)（函数调用栈）|
| BFS | O(n)（队列）|
| DFS 递归 | O(h)（树高 h）|

---

## 4. 均摊分析

某些操作**偶尔很慢，大多数时候很快**，均摊后每次仍为 O(1)。

**例：动态数组的 push_back**  
每次扩容时将容量翻倍：
- n 次 push_back 中，扩容复制的总次数 ≤ 1+2+4+...+n < 2n
- 均摊每次 push_back 代价：`2n/n = O(1)`

## 5. 代码示例：对比不同复杂度

```cpp
#include <bits/stdc++.h>
using namespace std;

// O(n)：线性扫描求最大值
int linearMax(vector<int>& a) {
    int mx = a[0];
    for (int x : a) mx = max(mx, x);
    return mx;
}

// O(n log n)：排序后取最大
int sortMax(vector<int> a) {
    sort(a.begin(), a.end());
    return a.back();
}

// O(n²)：双重循环（找两数之和，暴力）
bool twoSumBrute(vector<int>& a, int target) {
    int n = a.size();
    for (int i = 0; i < n; i++)
        for (int j = i+1; j < n; j++)
            if (a[i] + a[j] == target) return true;
    return false;
}

// O(n)：哈希表优化两数之和
bool twoSumHash(vector<int>& a, int target) {
    unordered_set<int> seen;
    for (int x : a) {
        if (seen.count(target - x)) return true;
        seen.insert(x);
    }
    return false;
}
```

## 6. 总结

- 分析时只保留**最高次项**，忽略系数
- 递归复杂度用**主定理**或递归树分析
- 竞赛中先估算 n 的范围，再决定算法
- **空间与时间往往可以互换**（空间换时间）
