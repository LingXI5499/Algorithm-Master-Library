# 04 - 哈希表 (Hash Table)

## 1. 概念解释

### 什么是哈希表？

哈希表（散列表）通过**哈希函数**将键映射到数组下标，从而实现 **O(1)** 平均时间复杂度的插入、删除和查找。

```
key ──哈希函数──▶ 数组下标 ──▶ value
"apple"  ──h()──▶    2      ──▶  5
"banana" ──h()──▶    7      ──▶  3
```

### 哈希函数

一个好的哈希函数应满足：
1. **计算快速**
2. **分布均匀**（减少冲突）

常用整数哈希：`h(k) = k % M`（M 取质数）

字符串哈希：

```cpp
// 多项式滚动哈希
unsigned long long strHash(const string& s) {
    unsigned long long h = 0;
    for (char c : s) h = h * 131 + c;
    return h;
}
```

### 冲突解决

**链地址法（拉链法）**：每个槽位维护一个链表，冲突的键都放入链表。

**开放寻址法**：冲突时按某种规则探测下一个空槽（线性探测、二次探测等）。

| 方法 | 优点 | 缺点 |
|------|------|------|
| 链地址法 | 删除简单，负载因子 > 1 时仍可用 | 额外指针开销 |
| 开放寻址法 | 缓存友好 | 易聚集，删除复杂 |

## 2. 手写哈希表（链地址法）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1e5 + 3;  // 质数
vector<pair<int,int>> table[MOD];  // table[h] = [(key,val), ...]

void insert(int key, int val) {
    int h = ((key % MOD) + MOD) % MOD;
    for (auto& p : table[h])
        if (p.first == key) { p.second = val; return; }
    table[h].push_back({key, val});
}

int query(int key) {
    int h = ((key % MOD) + MOD) % MOD;
    for (auto& p : table[h])
        if (p.first == key) return p.second;
    return -1;  // 不存在
}

void erase(int key) {
    int h = ((key % MOD) + MOD) % MOD;
    auto& v = table[h];
    v.erase(remove_if(v.begin(), v.end(),
        [key](const pair<int,int>& p){ return p.first == key; }), v.end());
}
```

## 3. C++ STL 哈希容器

### `unordered_map`（键值对）

```cpp
#include <unordered_map>
unordered_map<string, int> freq;
freq["apple"]++;
freq["banana"] += 2;

if (freq.count("apple")) cout << freq["apple"] << "\n"; // 1

// 遍历
for (auto& [key, val] : freq)
    cout << key << ": " << val << "\n";

freq.erase("apple");
```

### `unordered_set`（集合）

```cpp
#include <unordered_set>
unordered_set<int> seen;
seen.insert(3);
seen.insert(5);
cout << seen.count(3); // 1（存在）
cout << seen.count(7); // 0（不存在）
```

> **注意**：STL 的 `unordered_map`/`unordered_set` 在竞赛中有被卡哈希的风险，可以使用自定义哈希：

```cpp
struct custom_hash {
    size_t operator()(int x) const {
        x = ((x >> 16) ^ x) * 0x45d9f3b;
        x = ((x >> 16) ^ x) * 0x45d9f3b;
        x = (x >> 16) ^ x;
        return x;
    }
};
unordered_map<int, int, custom_hash> mp;
```

## 4. 哈希表的经典应用

### 两数之和（LeetCode 1）

```cpp
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int,int> mp;  // value -> index
    for (int i = 0; i < (int)nums.size(); i++) {
        int need = target - nums[i];
        if (mp.count(need)) return {mp[need], i};
        mp[nums[i]] = i;
    }
    return {};
}
```

### 字母异位词分组（LeetCode 49）

```cpp
vector<vector<string>> groupAnagrams(vector<string>& strs) {
    unordered_map<string, vector<string>> mp;
    for (auto& s : strs) {
        string key = s;
        sort(key.begin(), key.end());
        mp[key].push_back(s);
    }
    vector<vector<string>> res;
    for (auto& [k, v] : mp) res.push_back(v);
    return res;
}
```

### LRU 缓存（LeetCode 146）

使用**哈希表 + 双向链表**实现 O(1) 的 get 和 put。

```cpp
class LRUCache {
    int cap;
    list<pair<int,int>> lst;  // (key, val)，最近使用在前
    unordered_map<int, list<pair<int,int>>::iterator> mp;
public:
    LRUCache(int capacity) : cap(capacity) {}

    int get(int key) {
        if (!mp.count(key)) return -1;
        lst.splice(lst.begin(), lst, mp[key]);  // 移到头部
        return mp[key]->second;
    }

    void put(int key, int value) {
        if (mp.count(key)) {
            mp[key]->second = value;
            lst.splice(lst.begin(), lst, mp[key]);
        } else {
            if ((int)lst.size() == cap) {
                mp.erase(lst.back().first);
                lst.pop_back();
            }
            lst.push_front({key, value});
            mp[key] = lst.begin();
        }
    }
};
```

## 5. 布隆过滤器（Bloom Filter）

### 概念

布隆过滤器用**多个哈希函数 + 位数组**来判断元素是否**可能存在**。

- **误判率**：可能返回"存在"但实际不存在（假阳性）
- **无漏判**：若返回"不存在"则一定不存在
- **空间极省**：用 bit 存储，不存实际元素

```
插入 "apple"：
  h1("apple")=2 → bit[2]=1
  h2("apple")=7 → bit[7]=1
  h3("apple")=13 → bit[13]=1

查询 "apple"：bit[2] && bit[7] && bit[13] → 存在
查询 "grape"：若 h1("grape")=2, h2("grape")=5 → bit[5]=0 → 不存在
```

```cpp
#include <bitset>
#include <functional>

class BloomFilter {
    static const int M = 1 << 20;  // 位数组大小
    bitset<M> bits;
    vector<function<int(const string&)>> hashFuncs;

    int h(const string& s, int seed) {
        unsigned long long v = seed;
        for (char c : s) v = v * 131 + c;
        return v % M;
    }
public:
    BloomFilter() {
        for (int seed : {1, 3, 7, 13, 31})
            hashFuncs.push_back([this, seed](const string& s){ return h(s, seed); });
    }

    void insert(const string& s) {
        for (auto& f : hashFuncs) bits.set(f(s));
    }

    bool mightContain(const string& s) {
        for (auto& f : hashFuncs)
            if (!bits.test(f(s))) return false;
        return true;
    }
};
```

## 6. 总结

| 场景 | 推荐结构 |
|------|----------|
| 键值映射，O(1) 查询 | `unordered_map` |
| 去重/判存在 | `unordered_set` |
| LRU 缓存 | 哈希表 + 双向链表 |
| 海量数据去重（允许误判） | 布隆过滤器 |
| 区间有序操作（如 floor/ceil） | `map`/`set`（红黑树，O(log n)）|
