# 03 - 栈与队列 (Stack & Queue)

## 1. 栈 (Stack)

### 概念

栈是**后进先出（LIFO）**的线性数据结构，只允许在**栈顶**进行插入（push）和删除（pop）操作。

```
push(1) → push(2) → push(3)
栈内状态（底 → 顶）：[1, 2, 3]
pop() → 返回 3
```

| 操作 | 时间复杂度 |
|------|-----------|
| push（入栈） | O(1) |
| pop（出栈） | O(1) |
| peek/top（查看栈顶） | O(1) |

### C++ STL 使用

```cpp
#include <stack>
stack<int> st;
st.push(1);
st.push(2);
cout << st.top();   // 2
st.pop();
cout << st.empty(); // false
cout << st.size();  // 1
```

### 手写栈（数组模拟）

```cpp
const int MAXN = 1e5 + 5;
int stk[MAXN], top = 0;

void push(int x)   { stk[++top] = x; }
void pop()         { top--; }
int  peek()        { return stk[top]; }
bool empty()       { return top == 0; }
```

## 2. 队列 (Queue)

### 概念

队列是**先进先出（FIFO）**的线性数据结构，在队尾插入（enqueue），在队头删除（dequeue）。

```
enqueue(1) → enqueue(2) → enqueue(3)
队列状态（头 → 尾）：[1, 2, 3]
dequeue() → 返回 1
```

### C++ STL 使用

```cpp
#include <queue>
queue<int> q;
q.push(1); q.push(2); q.push(3);
cout << q.front(); // 1
q.pop();
cout << q.back();  // 3
```

### 循环队列（数组模拟）

```cpp
const int MAXN = 1e5 + 5;
int que[MAXN], head = 0, tail = 0;

void enqueue(int x) { que[tail++ % MAXN] = x; }
void dequeue()      { head++; }
int  front()        { return que[head % MAXN]; }
bool empty()        { return head == tail; }
```

## 3. 双端队列 (Deque)

双端队列允许在两端插入和删除。

```cpp
#include <deque>
deque<int> dq;
dq.push_front(1);  // 从头插入
dq.push_back(2);   // 从尾插入
dq.pop_front();    // 从头删除
dq.pop_back();     // 从尾删除
```

## 4. 单调栈

### 概念

单调栈维护栈内元素**单调递增**或**单调递减**的顺序。  
经典用途：**找每个元素左/右第一个更大（或更小）的元素**，时间复杂度 O(n)。

### 模板：下一个更大元素

```cpp
// 对每个 nums[i]，找其右侧第一个比它大的元素
vector<int> nextGreater(vector<int>& nums) {
    int n = nums.size();
    vector<int> res(n, -1);
    stack<int> st;  // 存下标，栈内 nums[st.top()] 单调递减

    for (int i = 0; i < n; i++) {
        while (!st.empty() && nums[i] > nums[st.top()]) {
            res[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }
    return res;
}
```

### 例题：柱状图中的最大矩形（LeetCode 84）

```cpp
int largestRectangleArea(vector<int>& heights) {
    int n = heights.size();
    // 左边第一个比自己矮的柱子
    vector<int> left(n), right(n);
    stack<int> st;

    for (int i = 0; i < n; i++) {
        while (!st.empty() && heights[st.top()] >= heights[i]) st.pop();
        left[i] = st.empty() ? -1 : st.top();
        st.push(i);
    }
    while (!st.empty()) st.pop();
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && heights[st.top()] >= heights[i]) st.pop();
        right[i] = st.empty() ? n : st.top();
        st.push(i);
    }

    int ans = 0;
    for (int i = 0; i < n; i++)
        ans = max(ans, heights[i] * (right[i] - left[i] - 1));
    return ans;
}
```

### 例题：接雨水（LeetCode 42）

```cpp
int trap(vector<int>& height) {
    int ans = 0;
    stack<int> st;  // 单调递减栈（存下标）
    for (int i = 0; i < (int)height.size(); i++) {
        while (!st.empty() && height[i] > height[st.top()]) {
            int bot = st.top(); st.pop();
            if (st.empty()) break;
            int w = i - st.top() - 1;
            int h = min(height[i], height[st.top()]) - height[bot];
            ans += w * h;
        }
        st.push(i);
    }
    return ans;
}
```

## 5. 单调队列

### 概念

单调队列用双端队列维护窗口内的**最大值或最小值**，队首始终是当前窗口的最值，时间复杂度 O(n)。

### 模板：滑动窗口最大值（LeetCode 239）

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;  // 存下标，队首是当前窗口最大值的下标
    vector<int> res;

    for (int i = 0; i < (int)nums.size(); i++) {
        // 移出窗口外的队首
        while (!dq.empty() && dq.front() < i - k + 1) dq.pop_front();
        // 维护单调递减（从队尾移出所有比 nums[i] 小的）
        while (!dq.empty() && nums[dq.back()] < nums[i]) dq.pop_back();
        dq.push_back(i);
        if (i >= k - 1) res.push_back(nums[dq.front()]);
    }
    return res;
}
```

## 6. 栈的经典应用

### 括号匹配（LeetCode 20）

```cpp
bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        } else {
            if (st.empty()) return false;
            char top = st.top(); st.pop();
            if (c == ')' && top != '(') return false;
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
        }
    }
    return st.empty();
}
```

### 用两个栈实现队列（LeetCode 232）

```cpp
class MyQueue {
    stack<int> in, out;
    void transfer() {
        while (!in.empty()) { out.push(in.top()); in.pop(); }
    }
public:
    void push(int x) { in.push(x); }
    int pop()  { if (out.empty()) transfer(); int x = out.top(); out.pop(); return x; }
    int peek() { if (out.empty()) transfer(); return out.top(); }
    bool empty() { return in.empty() && out.empty(); }
};
```

## 7. 总结

| 结构 | 特点 | 典型应用 |
|------|------|----------|
| 栈 | LIFO，O(1) 进出 | 括号匹配、表达式求值、DFS |
| 队列 | FIFO，O(1) 进出 | BFS、任务调度 |
| 单调栈 | 维护单调性 | 下一更大元素、柱状图矩形面积 |
| 单调队列 | 维护区间最值 | 滑动窗口最值、DP 优化 |
