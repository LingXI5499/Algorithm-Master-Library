# 02 - 链表 (Linked List)

## 1. 概念解释

### 什么是链表？

链表是由若干**节点**组成的线性数据结构，每个节点存储**数据**和**指向下一节点的指针**。  
与数组不同，链表的节点在内存中**不连续**，通过指针串联。

```
单链表示意：
┌──────┐    ┌──────┐    ┌──────┐    ┌──────┐
│  1  │───▶│  2  │───▶│  3  │───▶│  4  │───▶ NULL
└──────┘    └──────┘    └──────┘    └──────┘
  head
```

### 链表 vs 数组

| 操作 | 数组 | 链表 |
|------|------|------|
| 随机访问 | O(1) | O(n) |
| 头部插入/删除 | O(n) | O(1) |
| 中间插入/删除（已知节点） | O(n) | O(1) |
| 尾部追加 | O(1) 均摊 | O(n)（单链表无尾指针）|
| 空间开销 | 低 | 高（额外指针） |

### 链表种类

- **单链表**：每个节点只有 `next` 指针
- **双向链表**：每个节点有 `prev` 和 `next` 指针
- **循环链表**：尾节点的 `next` 指向头节点

## 2. 单链表实现

```cpp
#include <bits/stdc++.h>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

// ——— 常用操作 ———

// 在链表头部插入节点
ListNode* insertHead(ListNode* head, int val) {
    ListNode* node = new ListNode(val);
    node->next = head;
    return node;   // 新节点成为头节点
}

// 删除第一个值为 val 的节点
ListNode* deleteVal(ListNode* head, int val) {
    ListNode dummy(0);
    dummy.next = head;
    ListNode* prev = &dummy;
    while (prev->next) {
        if (prev->next->val == val) {
            ListNode* del = prev->next;
            prev->next = del->next;
            delete del;
            break;
        }
        prev = prev->next;
    }
    return dummy.next;
}

// 打印链表
void print(ListNode* head) {
    while (head) {
        cout << head->val;
        if (head->next) cout << " -> ";
        head = head->next;
    }
    cout << "\n";
}
```

## 3. 链表反转

### 迭代版本

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* curr = head;
    while (curr) {
        ListNode* nxt = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nxt;
    }
    return prev;
}
```

### 递归版本

```cpp
ListNode* reverseList(ListNode* head) {
    if (!head || !head->next) return head;
    ListNode* newHead = reverseList(head->next);
    head->next->next = head;
    head->next = nullptr;
    return newHead;
}
```

## 4. 快慢指针技巧

快慢指针是链表问题的核心技巧：慢指针每次走一步，快指针每次走两步。

### 找链表中点

```cpp
ListNode* findMiddle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;  // 奇数长度返回正中，偶数返回后中点
}
```

### 检测环（Floyd 判圈算法）

```cpp
bool hasCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

### 找环的入口节点

```cpp
ListNode* detectCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            // 相遇后，一个指针从头出发，一同走到入口
            ListNode* p = head;
            while (p != slow) {
                p = p->next;
                slow = slow->next;
            }
            return p;
        }
    }
    return nullptr;
}
```

## 5. 双向链表实现

```cpp
struct DListNode {
    int val;
    DListNode* prev;
    DListNode* next;
    DListNode(int x) : val(x), prev(nullptr), next(nullptr) {}
};

class DoublyLinkedList {
    DListNode* head;
    DListNode* tail;
public:
    DoublyLinkedList() : head(nullptr), tail(nullptr) {}

    void pushBack(int val) {
        DListNode* node = new DListNode(val);
        if (!tail) {
            head = tail = node;
        } else {
            tail->next = node;
            node->prev = tail;
            tail = node;
        }
    }

    void remove(DListNode* node) {
        if (node->prev) node->prev->next = node->next;
        else head = node->next;
        if (node->next) node->next->prev = node->prev;
        else tail = node->prev;
        delete node;
    }
};
```

## 6. 链表排序（归并排序）

```cpp
ListNode* merge(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode* cur = &dummy;
    while (l1 && l2) {
        if (l1->val <= l2->val) { cur->next = l1; l1 = l1->next; }
        else                    { cur->next = l2; l2 = l2->next; }
        cur = cur->next;
    }
    cur->next = l1 ? l1 : l2;
    return dummy.next;
}

ListNode* sortList(ListNode* head) {
    if (!head || !head->next) return head;
    // 找中点，断开
    ListNode* slow = head;
    ListNode* fast = head->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    ListNode* mid = slow->next;
    slow->next = nullptr;
    return merge(sortList(head), sortList(mid));
}
```

## 7. 经典例题

### 例题 1：合并两个有序链表（LeetCode 21）

```cpp
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode* cur = &dummy;
    while (l1 && l2) {
        if (l1->val <= l2->val) { cur->next = l1; l1 = l1->next; }
        else                    { cur->next = l2; l2 = l2->next; }
        cur = cur->next;
    }
    cur->next = l1 ? l1 : l2;
    return dummy.next;
}
```

### 例题 2：删除链表倒数第 N 个节点（LeetCode 19）

```cpp
ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy(0);
    dummy.next = head;
    ListNode* fast = &dummy;
    ListNode* slow = &dummy;
    for (int i = 0; i <= n; i++) fast = fast->next;
    while (fast) { fast = fast->next; slow = slow->next; }
    ListNode* del = slow->next;
    slow->next = del->next;
    delete del;
    return dummy.next;
}
```

### 例题 3：K 个一组翻转链表（LeetCode 25）

```cpp
ListNode* reverseKGroup(ListNode* head, int k) {
    ListNode* cur = head;
    int cnt = 0;
    while (cur && cnt < k) { cur = cur->next; cnt++; }
    if (cnt < k) return head;  // 不足 k 个，不翻转

    // 翻转前 k 个
    ListNode* prev = nullptr;
    ListNode* node = head;
    for (int i = 0; i < k; i++) {
        ListNode* nxt = node->next;
        node->next = prev;
        prev = node;
        node = nxt;
    }
    // head 现在是翻转后的尾节点，连接后续
    head->next = reverseKGroup(node, k);
    return prev;
}
```

## 8. 总结

| 技巧 | 适用场景 |
|------|----------|
| 虚拟头节点（dummy） | 统一头节点的插入/删除逻辑 |
| 快慢指针 | 找中点、检测环、找倒数第 N 个 |
| 递归 | 反转、K 组翻转 |
| 归并排序 | 链表排序（O(n log n)，O(log n) 栈空间） |
