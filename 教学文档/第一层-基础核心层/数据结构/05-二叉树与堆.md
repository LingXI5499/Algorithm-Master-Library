# 05 - 二叉树与堆 (Binary Tree & Heap)

## 1. 二叉树基础

### 概念

二叉树是每个节点**最多有两个子节点**的树形结构，分别称为**左子树**和**右子树**。

```
        1
       / \
      2   3
     / \   \
    4   5   6
```

**常见特殊二叉树**：
- **满二叉树**：所有内部节点都有两个子节点
- **完全二叉树**：除最后一层外每层都满，最后一层从左到右填充
- **平衡二叉树**：任意节点的左右子树高度差 ≤ 1

### 节点定义

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

## 2. 二叉树遍历

### 前序 / 中序 / 后序（递归）

```cpp
// 前序：根 → 左 → 右
void preorder(TreeNode* root, vector<int>& res) {
    if (!root) return;
    res.push_back(root->val);
    preorder(root->left, res);
    preorder(root->right, res);
}

// 中序：左 → 根 → 右（BST 中序得有序序列）
void inorder(TreeNode* root, vector<int>& res) {
    if (!root) return;
    inorder(root->left, res);
    res.push_back(root->val);
    inorder(root->right, res);
}

// 后序：左 → 右 → 根
void postorder(TreeNode* root, vector<int>& res) {
    if (!root) return;
    postorder(root->left, res);
    postorder(root->right, res);
    res.push_back(root->val);
}
```

### 中序遍历（迭代，用栈）

```cpp
vector<int> inorderIterative(TreeNode* root) {
    vector<int> res;
    stack<TreeNode*> st;
    TreeNode* cur = root;
    while (cur || !st.empty()) {
        while (cur) { st.push(cur); cur = cur->left; }
        cur = st.top(); st.pop();
        res.push_back(cur->val);
        cur = cur->right;
    }
    return res;
}
```

### 层序遍历（BFS）

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    if (!root) return {};
    vector<vector<int>> res;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int sz = q.size();
        vector<int> level;
        while (sz--) {
            TreeNode* node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        res.push_back(level);
    }
    return res;
}
```

## 3. 二叉搜索树 (BST)

### 特性

- 左子树所有节点 < 当前节点 < 右子树所有节点
- **中序遍历**得到有序序列
- 平衡时查找/插入/删除均为 O(log n)

### 插入与查找

```cpp
TreeNode* insert(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    if (val < root->val) root->left  = insert(root->left,  val);
    else if (val > root->val) root->right = insert(root->right, val);
    return root;
}

bool search(TreeNode* root, int val) {
    if (!root) return false;
    if (val == root->val) return true;
    return val < root->val ? search(root->left, val) : search(root->right, val);
}
```

### 删除节点（LeetCode 450）

```cpp
// 找到最小节点（用于替换被删除节点）
TreeNode* minNode(TreeNode* root) {
    while (root->left) root = root->left;
    return root;
}

TreeNode* deleteNode(TreeNode* root, int key) {
    if (!root) return nullptr;
    if (key < root->val)
        root->left  = deleteNode(root->left,  key);
    else if (key > root->val)
        root->right = deleteNode(root->right, key);
    else {
        if (!root->left)  { TreeNode* r = root->right; delete root; return r; }
        if (!root->right) { TreeNode* l = root->left;  delete root; return l; }
        // 用右子树最小节点替换
        TreeNode* mn = minNode(root->right);
        root->val   = mn->val;
        root->right = deleteNode(root->right, mn->val);
    }
    return root;
}
```

### 最近公共祖先（LCA，LeetCode 235/236）

```cpp
// BST 的 LCA（利用 BST 性质）
TreeNode* lcaBST(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (p->val < root->val && q->val < root->val) return lcaBST(root->left,  p, q);
    if (p->val > root->val && q->val > root->val) return lcaBST(root->right, p, q);
    return root;
}

// 普通二叉树的 LCA
TreeNode* lca(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;
    TreeNode* left  = lca(root->left,  p, q);
    TreeNode* right = lca(root->right, p, q);
    if (left && right) return root;  // p、q 分居两侧
    return left ? left : right;
}
```

## 4. 堆 (Heap)

### 概念

堆是一棵**完全二叉树**，满足堆性质：
- **最大堆**：每个节点的值 ≥ 子节点的值（根为最大值）
- **最小堆**：每个节点的值 ≤ 子节点的值（根为最小值）

通常用**数组**存储（下标从 1 开始）：
- 节点 `i` 的左孩子：`2i`，右孩子：`2i+1`，父节点：`i/2`

### 堆的基本操作

```cpp
// 最大堆实现
class MaxHeap {
    vector<int> h;
    int n = 0;

    void up(int i) {
        while (i > 1 && h[i] > h[i/2]) {
            swap(h[i], h[i/2]);
            i /= 2;
        }
    }

    void down(int i) {
        while (2*i <= n) {
            int j = 2*i;
            if (j < n && h[j+1] > h[j]) j++;
            if (h[i] >= h[j]) break;
            swap(h[i], h[j]);
            i = j;
        }
    }

public:
    MaxHeap() : h(1) {}  // h[0] 不用

    void push(int val) {
        h.push_back(val); n++;
        up(n);
    }

    int top() { return h[1]; }

    void pop() {
        h[1] = h[n--]; h.pop_back();
        if (n) down(1);
    }

    bool empty() { return n == 0; }
};
```

### C++ STL 优先队列

```cpp
#include <queue>

// 最大堆（默认）
priority_queue<int> maxPQ;
maxPQ.push(3); maxPQ.push(1); maxPQ.push(5);
cout << maxPQ.top();  // 5

// 最小堆
priority_queue<int, vector<int>, greater<int>> minPQ;
minPQ.push(3); minPQ.push(1); minPQ.push(5);
cout << minPQ.top();  // 1

// 自定义比较（按 pair 第二元素升序）
auto cmp = [](pair<int,int> a, pair<int,int> b){ return a.second > b.second; };
priority_queue<pair<int,int>, vector<pair<int,int>>, decltype(cmp)> pq(cmp);
```

## 5. 堆排序

```cpp
void heapSort(vector<int>& a) {
    int n = a.size();
    // 建堆：从最后一个非叶节点向上 sift down
    auto down = [&](int i, int sz) {
        while (2*i+1 < sz) {
            int j = 2*i+1;
            if (j+1 < sz && a[j+1] > a[j]) j++;
            if (a[i] >= a[j]) break;
            swap(a[i], a[j]); i = j;
        }
    };
    for (int i = n/2 - 1; i >= 0; i--) down(i, n);
    // 反复将堆顶移到末尾
    for (int i = n-1; i > 0; i--) {
        swap(a[0], a[i]);
        down(0, i);
    }
}
```

## 6. Top K 问题

找数组中**最大的 K 个数**（维护大小为 K 的最小堆）：

```cpp
vector<int> topK(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> minPQ;  // 最小堆
    for (int x : nums) {
        minPQ.push(x);
        if ((int)minPQ.size() > k) minPQ.pop();  // 超出 k 个，弹出最小值
    }
    vector<int> res;
    while (!minPQ.empty()) { res.push_back(minPQ.top()); minPQ.pop(); }
    return res;
}
```

## 7. 二叉树序列化与反序列化

```cpp
// 前序遍历序列化（空节点用 "#" 表示）
string serialize(TreeNode* root) {
    if (!root) return "#,";
    return to_string(root->val) + "," + serialize(root->left) + serialize(root->right);
}

TreeNode* deserializeHelper(istringstream& ss) {
    string token;
    getline(ss, token, ',');
    if (token == "#") return nullptr;
    TreeNode* node = new TreeNode(stoi(token));
    node->left  = deserializeHelper(ss);
    node->right = deserializeHelper(ss);
    return node;
}

TreeNode* deserialize(string data) {
    istringstream ss(data);
    return deserializeHelper(ss);
}
```

## 8. 总结

| 知识点 | 核心操作 | 时间复杂度 |
|--------|----------|-----------|
| 二叉树遍历 | 递归/迭代/BFS | O(n) |
| BST 查找/插入 | 沿路比较 | O(log n) 平均 |
| 堆插入 | sift up | O(log n) |
| 堆删除堆顶 | sift down | O(log n) |
| Top K 问题 | 维护大小为 K 的堆 | O(n log k) |
| 堆排序 | 建堆 + 反复弹出 | O(n log n) |
