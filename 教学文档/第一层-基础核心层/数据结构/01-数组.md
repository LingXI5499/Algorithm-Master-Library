# 01 - 数组 (Array)

## 1. 概念解释

### 什么是数组？

数组是一种**线性数据结构**，在内存中以**连续地址**存储相同类型的元素。  
其最核心的特性是：**可以通过下标（索引）在 O(1) 时间内随机访问任意元素**。

```
索引:  0    1    2    3    4
      ┌────┬────┬────┬────┬────┐
值:   │ 10 │ 20 │ 30 │ 40 │ 50 │
      └────┴────┴────┴────┴────┘
地址: 100  104  108  112  116   （假设每个 int 占 4 字节）
```

`arr[i]` 的地址 = 起始地址 + `i × 元素大小`

### 静态数组 vs 动态数组

| 特性 | 静态数组 | 动态数组（如 `vector`）|
|------|----------|----------------------|
| 大小 | 编译时确定 | 运行时可变 |
| 扩容 | 不支持 | 均摊 O(1) 追加 |
| 内存 | 栈或静态区 | 堆 |

> **动态数组扩容策略**：当容量不足时，申请 **2倍** 原大小的新空间，复制元素后释放旧空间。均摊下每次 `push_back` 的时间复杂度为 O(1)。

### 基本操作复杂度

| 操作 | 时间复杂度 |
|------|-----------|
| 随机访问 | O(1) |
| 头部/中间插入或删除 | O(n) |
| 尾部追加（动态数组） | O(1) 均摊 |
| 搜索（无序） | O(n) |
| 搜索（有序 + 二分） | O(log n) |

## 2. 前缀和数组

### 概念

预处理数组 `prefix[i] = a[0] + a[1] + ... + a[i-1]`，之后任意区间 `[l, r]` 的和可在 **O(1)** 内查询：

```
sum(l, r) = prefix[r+1] - prefix[l]
```

### 代码示例

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n), prefix(n + 1, 0);

    for (int i = 0; i < n; i++) cin >> a[i];

    // 构建前缀和
    for (int i = 0; i < n; i++)
        prefix[i + 1] = prefix[i] + a[i];

    // 查询区间 [l, r]（0-indexed）的和
    int l, r;
    cin >> l >> r;
    cout << prefix[r + 1] - prefix[l] << "\n";
    return 0;
}
```

**二维前缀和**（矩阵子矩形求和）：

```cpp
// prefix[i][j] = 左上角(0,0)到(i-1,j-1)的矩形元素和
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        prefix[i][j] = a[i-1][j-1]
                     + prefix[i-1][j]
                     + prefix[i][j-1]
                     - prefix[i-1][j-1];

// 子矩形 (r1,c1) -> (r2,c2) 的和（0-indexed 原数组）
int query(int r1, int c1, int r2, int c2) {
    return prefix[r2+1][c2+1]
         - prefix[r1][c2+1]
         - prefix[r2+1][c1]
         + prefix[r1][c1];
}
```

## 3. 差分数组

### 概念

差分数组 `diff[i] = a[i] - a[i-1]`（`diff[0] = a[0]`）。  
对原数组区间 `[l, r]` 所有元素加 `v` 等价于：`diff[l] += v; diff[r+1] -= v;`  
最终还原：对差分数组求前缀和即得修改后的原数组。

> **用途**：大量区间更新操作时，将 O(n) 的区间修改降至 O(1)，最后一次性 O(n) 还原。

### 代码示例

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<long long> diff(n + 2, 0);

    // 读入原数组并构建差分
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        diff[i] += x;
        diff[i + 1] -= x;
    }

    // q 次区间加操作
    while (q--) {
        int l, r, v;
        cin >> l >> r >> v;   // 0-indexed
        diff[l] += v;
        diff[r + 1] -= v;
    }

    // 还原并输出
    long long cur = 0;
    for (int i = 0; i < n; i++) {
        cur += diff[i];
        cout << cur << " \n"[i == n - 1];
    }
    return 0;
}
```

## 4. 稀疏数组

当矩阵中绝大多数元素为 0（或默认值）时，用**三元组列表**压缩存储：

```cpp
struct Element {
    int row, col, val;
};

// 将普通矩阵压缩
vector<Element> compress(vector<vector<int>>& mat) {
    vector<Element> sparse;
    for (int i = 0; i < (int)mat.size(); i++)
        for (int j = 0; j < (int)mat[0].size(); j++)
            if (mat[i][j] != 0)
                sparse.push_back({i, j, mat[i][j]});
    return sparse;
}
```

## 5. 经典例题

### 例题 1：找到数组中消失的数字（LeetCode 448）

**思路**：利用数组下标作标记，将 `a[|a[i]|-1]` 取负，最后正数对应的下标即为缺失数字。

```cpp
vector<int> findDisappearedNumbers(vector<int>& nums) {
    int n = nums.size();
    for (int i = 0; i < n; i++) {
        int idx = abs(nums[i]) - 1;
        if (nums[idx] > 0) nums[idx] = -nums[idx];
    }
    vector<int> res;
    for (int i = 0; i < n; i++)
        if (nums[i] > 0) res.push_back(i + 1);
    return res;
}
```

### 例题 2：子数组和等于 K（LeetCode 560）

**思路**：前缀和 + 哈希表，统计 `prefix[j] - prefix[i] == k` 的对数。

```cpp
int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> cnt;
    cnt[0] = 1;
    int sum = 0, ans = 0;
    for (int x : nums) {
        sum += x;
        ans += cnt[sum - k];
        cnt[sum]++;
    }
    return ans;
}
```

### 例题 3：矩阵区域和（LeetCode 1314）

```cpp
vector<vector<int>> matrixBlockSum(vector<vector<int>>& mat, int k) {
    int n = mat.size(), m = mat[0].size();
    // 构建二维前缀和
    vector<vector<int>> pre(n + 1, vector<int>(m + 1, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            pre[i][j] = mat[i-1][j-1] + pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1];

    auto query = [&](int r1, int c1, int r2, int c2) {
        r1 = max(r1, 0); c1 = max(c1, 0);
        r2 = min(r2, n-1); c2 = min(c2, m-1);
        return pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1];
    };

    vector<vector<int>> ans(n, vector<int>(m));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            ans[i][j] = query(i-k, j-k, i+k, j+k);
    return ans;
}
```

## 6. 总结

| 技术 | 适用场景 | 时间复杂度 |
|------|----------|-----------|
| 前缀和 | 静态区间求和 | 预处理 O(n)，查询 O(1) |
| 差分数组 | 区间批量修改 | 更新 O(1)，还原 O(n) |
| 稀疏数组 | 大量零元素的矩阵 | 空间 O(非零元素数) |
