## 🚦 学习路线建议

```
入门 (1-3个月)
  └─ 数组 → 链表 → 栈队列 → 哈希表
  └─ 复杂度分析 → 排序 → 二分 → 双指针
  └─ DFS/BFS → 贪心 → DP基础

进阶 (3-6个月)
  └─ 二叉树 → 堆 → 并查集 → 树状数组 → 线段树 → Trie
  └─ 背包DP → 图论 → KMP

高级 (6-12个月)
  └─ 网络流 → 计算几何 → 高级DP优化
```

> **建议**：每学完一个知识点，立即在 LeetCode / 洛谷 上找 2-3 道对应例题练手。
